# Changelog

Подробные описания изменений приложения — в [docs/SPEC.md](docs/SPEC.md).

## 1.5.0 — 2026-09-09

Свободная схема — новый тип страницы рядом с холстом.

- «Схема»: узлы лежат там, где положил, размер тянется за угол, стрелки сами
  выбирают сторону. На схеме лежит только то, что вы на неё положили,
  а не все узлы проекта.
- «↧ Положить узел» в панели страницы выносит на схему существующий узел.
- Холст с колонками не изменился: там колонка по-прежнему = глубина зависимости,
  раскладку считает граф, а стрелки идут слева направо.
- Сетка теперь двигается и масштабируется вместе с холстом.

## 1.4.0 — 2026-09-09

Редактирование нод: панель больше не мешает.

- Инспектор стал оверлеем и не отжимает холст. Ширина 380 px вместо 430,
  тянется за левый край, значение запоминается.
- Панель не вылезает при каждом клике по узлу. Открыть — Enter, закрыть — Enter или Esc.
- «Зависимости» переписаны: вместо чекбокса на каждый узел проекта — чипы выбранного
  и поиск по названию или id. Появился блок «что откроет этот узел».
- Миникарта и нижняя панель действий уезжают из-под открытой панели.

## 1.3.0 — 2026-09-09

Сборка на Vite. Поведение не менялось — те же функции, та же вёрстка, те же данные;
изменилась только раскладка кода. Старые файлы открываются как раньше.

- `app/graph_studio.html` разрезан на `index.html`, `src/main.js`, `src/styles.css`;
  PWA-обвязка переехала в `public/`. Каталог `app/` удалён, последняя однофайловая
  версия достаётся из тега `v1.2.1-singlefile`.
- Локальный запуск: `npm run dev` (или `start.command`), сборка: `npm run build`.
- Экспорт `viewer.html` теперь собирается из отдельного самодостаточного шаблона
  и доступен только в собранной версии, не в режиме разработки.
- Образ собирается в две стадии; `/assets/` кэшируется на год, старый адрес
  `/graph_studio.html` отдаёт 301 на корень.

## 1.2.1 — 2026-09-09

Подготовка к серверной версии. Новых функций нет — убрано то, что ломало бы совместную
работу и теряло данные. Старые файлы открываются как раньше, это закрыто отдельным тестом.

- Отрисовка холста больше не пишет в проект: засев свободных позиций вынесен в явное действие.
- Камера холста переехала в `localStorage` — это личное состояние, а не часть документа.
  Камера из старых файлов по-прежнему читается.
- Ресайз областей и стикеров сохраняется по отпусканию кнопки; побочно починена отмена ресайза.
- `sw.js` заменён на kill-switch: прежний воркер кэшировал всё навсегда и отдавал HTML-оболочку
  с кодом 200 на упавший запрос. Установка как PWA может перестать предлагаться.
- Бэкап всех проектов теперь включает корзину и снимки версий (раньше молча терял и то, и другое).
- Восстановление из бэкапа при совпадении идентификаторов спрашивает, а не затирает молча.
- Папка-хранилище больше не удаляет проект из базы, если файл в ней исчез.
- Напоминание о резервной копии и `navigator.storage.persist()` при старте.
- Новый набор тестов `test/legacy.js` — совместимость со старыми форматами файлов.

## 1.2.0 — 2026-08-03

Упаковка в продукт и деплой. Само приложение не менялось.

- Структура репозитория: приложение вынесено в `app/`, ТЗ — в `docs/SPEC.md`.
- Docker: `nginx:stable-alpine`, статика из `app/`, `/` открывает приложение,
  `/healthz` для проверок, no-cache на app-shell (`graph_studio.html`, `sw.js`,
  `manifest.webmanifest`), gzip.
- `docker-compose.yml` — контейнер слушает только `127.0.0.1:8081`.
- Конфиги host-nginx для `graph.heeprod.ru` и скрипт обновления `deploy/deploy.sh`.
- README, LICENSE (MIT), инструкция по деплою.
- Публичный релиз: https://graph.heeprod.ru
