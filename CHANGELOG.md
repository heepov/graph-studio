# Changelog

Подробные описания изменений приложения — в [docs/SPEC.md](docs/SPEC.md).

## 1.2.1 — 2026-09-09

Подготовка к серверной версии. Новых функций нет — убрано то, что ломало бы совместную
работу и теряло данные. Старые файлы открываются как раньше, это закрыто отдельным тестом.

- Отрисовка холста больше не пишет в проект: засев свободных позиций вынесен в явное действие.
- Камера холста переехала в `localStorage` — это личное состояние, а не часть документа.
  Камера из старых файлов по-прежнему читается.
- Ресайз областей и стикеров сохраняется по отпусканию кнопки; побочно починена отмена ресайза.
- `sw.js` заменён на kill-switch: прежний воркер кэшировал всё навсегда и отдавал HTML-оболочку
  с кодом 200 на упавший запрос. Установка как PWA может перестать предлагаться.
- Бэкап всех проектов теперь включает корзину и снимки версий (раньше молча терял и то, и другое).
- Восстановление из бэкапа при совпадении идентификаторов спрашивает, а не затирает молча.
- Папка-хранилище больше не удаляет проект из базы, если файл в ней исчез.
- Напоминание о резервной копии и `navigator.storage.persist()` при старте.
- Новый набор тестов `test/legacy.js` — совместимость со старыми форматами файлов.

## 1.2.0 — 2026-08-03

Упаковка в продукт и деплой. Само приложение не менялось.

- Структура репозитория: приложение вынесено в `app/`, ТЗ — в `docs/SPEC.md`.
- Docker: `nginx:stable-alpine`, статика из `app/`, `/` открывает приложение,
  `/healthz` для проверок, no-cache на app-shell (`graph_studio.html`, `sw.js`,
  `manifest.webmanifest`), gzip.
- `docker-compose.yml` — контейнер слушает только `127.0.0.1:8081`.
- Конфиги host-nginx для `graph.heeprod.ru` и скрипт обновления `deploy/deploy.sh`.
- README, LICENSE (MIT), инструкция по деплою.
- Публичный релиз: https://graph.heeprod.ru

## 1.2 — 2026-07-29

PWA + File System Access.

- Установка как приложение (собственное окно, иконка в доке, офлайн).
- Проекты в реальных `.json` на диске с автосохранением.
- Папка-хранилище в стиле Obsidian: одна папка — все проекты.
- Фасетные фильтры с числом подходящих узлов у каждого значения.
- Инлайн-создание типов/статусов/категорий/колонок прямо из инспектора.
